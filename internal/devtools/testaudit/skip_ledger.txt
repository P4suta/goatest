# Tests that are allowed to skip, one "package Test" per line, sorted.
#
# A skip is a test that did not run. On this repository's own suite that has to
# be a decision somebody made and wrote down, because the alternative is what
# used to happen: a runner without `git` on PATH retired every end-to-end test
# and a non-verbose `go test` reported the remainder as `ok`.
#
# This ledger is a ratchet in the shrinking direction. It records the skips that
# survive GOATEST_TEST_REQUIRE_TOOLS, which are of exactly two kinds:
#
#   - a platform cannot do what the test is about. Every entry below is a test
#     of how goatest treats a symbolic link, or of a path behaviour Windows does
#     not share, and on a platform that cannot make the thing there is nothing
#     to observe. These fire on Windows and not on Unix, which is why running
#     the suite on one operating system cannot prove an entry is stale.
# A helper process entry point used to be the second kind, and is not any more.
# It asserted nothing in an ordinary run, so it skipped - and goatest's own
# accounting treats a selected target that skipped as missing evidence, which is
# correct. It asserts that its variable did not select it now, which is small and
# true, so it runs.
#
# A skip for a missing tool belongs to neither kind and must not be added here.
# Set GOATEST_TEST_REQUIRE_TOOLS=1 in CI and the harness will fail instead.
